# ТСД Telnet

Telnet-клиент для складского терминала сбора данных (ТСД) на **Android 4.0.4 (API 15)**.
Написан под iData 95, но рассчитан на любой ТСД с Android 4.x: только системные классы
`android.*`, без AndroidX и внешних библиотек.

Зачем: подключиться к старой складской системе по telnet, рисовать её VT100/ANSI-экраны
(позиционирование курсора, цвета, псевдографика), работать со сканером штрихкодов и
физической клавиатурой ТСД. Логин, пароль и «коды кнопок» берутся из текстового файла
на карте памяти, поэтому их можно менять без пересборки APK.

## Возможности

* Полноценная эмуляция терминала **VT100/ANSI**: CSI, цвета (16 цветов), очистка,
  область прокрутки, альтернативный экран, перенос строки, история (scrollback).
* Переговоры telnet: `IAC`, `ECHO`, `NAWS` (сообщает серверу размер экрана), `TTYPE`.
* Кодировки `cp866`, `windows-1251`, `koi8-r`, `utf-8` — выбор в файле и переключение
  в меню на ходу.
* Сканер штрихкодов: и режим клавиатуры (включая пакетную вставку), и широковещательные
  рассылки iScan (`android.intent.action.SCANRESULT`, extra `value`).
* Клавиши ТСД уходят на сервер как есть; в файле задаются только исключения
  (подмена последовательностью или отключение клавиши).
* Автоответ на приглашения логина/пароля и произвольные пары «приглашение → ответ».
* Встроенный моношрифт с кириллицей и рамками, подгонка размера на устройстве.
* Экран не гаснет, полноэкранный режим, прокрутка истории пальцем.
* Лог в файл на карте памяти для разбора проблем на месте.

## Сборка

```bat
gradlew.bat :app:assembleDebug
```

APK: `app\build\outputs\apk\debug\app-debug.apk`.

Собрано с `minSdkVersion 15`, `targetSdkVersion 33`, AGP 9.1.0 / Gradle 9.3.1 / JDK 21.

## Установка

```bat
adb push telnet.ini.example /sdcard/telnet.ini
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Если файла `/sdcard/telnet.ini` нет, приложение создаст его само с комментариями.

## Настройка

Полное руководство — в [README-ТСД.md](README-ТСД.md): все параметры конфигурации,
работа со сканером iData, подбор кодировки, коды клавиш, частые проблемы.

Кратко: скопируйте `telnet.ini.example` в `/sdcard/telnet.ini`, укажите адрес сервера,
логин и пароль. Пароль и адрес сервера в репозиторий не попадают — в примере стоят
заглушки.

## Проверка логики без устройства

```bat
tools\selftest\run.bat
```

Скрипт компилирует Android-независимую часть приложения вместе с заглушкой
`android.view.KeyEvent` и прогоняет 90 проверок: эмулятор VT100/ANSI, кодировки,
разбор конфига, раскладка клавиш, telnet-переговоры, сквозной обмен с локальным
сервером, проверка разметки (защита от падения при запуске).

## Структура

| Файл | Назначение |
|---|---|
| `MainActivity.java` | экран, меню, клавиши ТСД, приём сканера, переподключение |
| `TelnetClient.java` | сокет, два потока, переговоры telnet, автоответ на приглашения |
| `TelnetConfig.java` | разбор `/sdcard/telnet.ini`, создание шаблона, escape-последовательности |
| `AnsiParser.java` | разбор VT100/ANSI: CSI, цвета, очистка, альтернативный экран |
| `TerminalScreen.java` | сетка символов, курсор, область прокрутки, история |
| `TerminalView.java` | отрисовка сетки, цвета ANSI, прокрутка пальцем, псевдографика |
| `KeyMapper.java` | клавиша ТСД → байты на сервер, подмена и блокировка из конфига |
| `CharsetKit.java` | cp866 / windows-1251 / koi8-r / utf-8 |
| `LogKit.java` | лог в файл на карте памяти |
